- Merge the pre-release fixes and retained local workflow changes: source and
  derivative bindings, exact reducer handoffs, and candidate-reduction checks.
- Include optional batch sector slicing. Keep numerical point-DE production and
  the private BlockIBP adapter out of the release branch.

  coupled twistor/Kira profile; update their references and remaining tests.

  basis/gauge checks and structural serialization, retaining independent gates.

- Replace the earlier example exports with the AI4UT manuscript's final 37-,
  61- and 40-master results. Each family contains only the raw canonical basis,
  ordered alphabet and logarithmic Atilde matrix.
- Refresh installation, reading instructions and dependency provenance. Check
  package integrity and small synthetic regressions without rerunning the
  article's physical examples.

## Retained workflow

The release retains physical derivative preparation, exact source and reducer
bindings, candidate IBP reduction, bounded core methods, tail completion and
independent canonical/final checks. Optional parameterization, Kira/Blade/FIRE7/
NeatIBP adapters, dlog reconstruction from supplied samples, local execution,
batch slicing and exact FLINT arithmetic are documented with their own scopes.
External source snapshots retain their upstream licenses and provenance.

No release tag or DOI is assigned by this branch update.
