## Scientific methods and external code

CANON orchestrates and checks calculations that use existing scientific methods.
When publishing a calculation, cite the tools and methods actually used as well
as CANON. Package documentation provides the appropriate citations:

- [DlogBasis-refine](external/DlogBasis-refine/README.md)
- [CANONICA](external/CANONICA/README)
- [Libra](external/Libra/Readme.md)
- [Fermatica](external/Fermatica/README.md) and [Fermat](external/Fermat/README.md)
- [INITIAL](external/INITIAL/README.md)
- [FiniteFlow](external/FiniteFlow/README.md)
- [Kira](external/Kira/README.rst)
- [Singular](external/Singular/README.md)

The [method catalog](methods/README.md) and individual cards state the
implemented methods, references and scope. The [example guide](examples/README.md)
identifies the saved mathematical results used in the article.
